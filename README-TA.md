# Point Pedro GitHub PWA v1.0.0.2

சமீபத்திய அமைப்புக்கான முழு வழிமுறை: [WEB_PUSH_SETUP_TAMIL.md](WEB_PUSH_SETUP_TAMIL.md)

- GitHub Pages + Google Apps Script + Google Sheets + GitHub Actions மட்டும்.
- ZIP-ன் Files-ஐ Repository Root-ல் Extract செய்து Upload செய்யுங்கள்.
- Firebase/Netlify இல்லை.
- `push-config.json`-ல் Public VAPID Key மட்டும் சேர்க்கவும்.
- GitHub Actions Secrets மற்றும் Apps Script Script Properties அமைக்காமல் Real Push வேலை செய்யாது.
- Booking UI-க்கான GitHub Toolbar அகற்றப்பட்டது. Device Setup முடியும் வரை சிறிய Bell Setup Button மட்டும் காட்டப்படும்.
- ஏற்கனவே உள்ள Apps Script Application மற்றும் அதன் Login பாதுகாக்கப்படும்.
